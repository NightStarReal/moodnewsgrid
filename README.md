# moodnewsgrid

Прототип новостника, где можно читать новости в различных настроениях. 
Доступные настроения:
- :) веселое
- :( грустное
- :| нейтральное
- (: ироничное

Как работает:
Запустите
`docker compose up`
Чтобы запустить nginx сервер. Далее перейдите на localhost:80, чтобы увидеть новостник.
Чтобы прочитать новость в определенном настроении, нажмите на новость, затем выберите настроение, которое хотите. "Душное" настроение вернет текст новости к оригиналу.
